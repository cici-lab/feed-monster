# 小怪兽投喂 (Monster Feeder)

一个使用 Kaplay 游戏引擎开发的互动小游戏，支持 Electron 桌面应用。玩家通过拖拽食物投喂小怪兽，收集食材在合成炉中制作料理并解锁料理图鉴。

## 运行方式

```bash
# 安装依赖
npm install

# 开发模式（浏览器）
npm run dev

# Electron 开发模式
npm run electron:dev

# 打包桌面应用
npm run electron:build
```

## 技术栈

- **游戏引擎**: Kaplay (Kaboom.js fork)
- **构建工具**: Vite
- **桌面框架**: Electron
- **开发语言**: JavaScript (ES6+)
- **UI弹窗**: 原生 HTML/CSS（图鉴、配方面板）

## 已完成功能

### 核心玩法

**小怪兽角色系统**
- 状态切换：待机/开心/伤心/吃东西
- 眼睛跟随鼠标移动
- 成长系统（吃食物后变大）
- 饱食度机制（随时间下降）
- 生命值系统（饱食度过低时减少）

**食物系统**
- 28种食物，6大类别：自然/液体/奇怪/美味/抽象
- 食物从屏幕边缘飘入，带摆动动画
- 彩虹色变化效果
- 不可食用食物的拒绝机制
- 游戏重启时正确清除并重新生成食物

**拖拽交互**
- 拖拽食物到小怪兽投喂
- 投掷力度加成（最高2倍）
- 连击系统
- 拖拽轨迹视觉效果

### 合成系统

- 中世纪魔法炉子 UI（带符文、火焰动画）
- 收集3个食材进行合成
- 维度阈值配方（nature/liquid/weird/delicious/abstract）
- 优先级匹配（多个候选时取优先级最高）
- 兜底料理机制（随手合成也能得到低阶料理）
- 料理解锁与进度保存（localStorage）
- 合成成功自动激活对应 buff（详见 Buff 系统）

### UI系统

- 分数显示
- 饱食度进度条（颜色随数值变化）
- 生命值进度条
- 全屏按钮（支持 Electron 和浏览器）
- 右下角操作提示

### Buff 系统

- 合成料理产出即时临时 buff，效果回到主循环影响游戏体验
- 每个配方绑定 1 个 buff，合成成功时自动激活
- 9 种 buff 类型：

| Buff | 图标 | 效果 | 持续时间 |
|------|------|------|---------|
| 饱食守护 | 🛡️ | 饱食度暂停下降 | 6s |
| 元素循环 | ♻️ | 饱食度下降减半 | 10s |
| 液态护盾 | 💚 | 生命值暂停下降 | 8s |
| 饱餐盛宴 | ⭐ | 所有得分翻倍 | 12s |
| 食物丰收 | 🌾 | 食物生成速度翻倍 | 12s |
| 虚空侵蚀 | 🌀 | 厌恶食物视为普通 | 12s |
| 属性共鸣 | 🔮 | 特定类别食物得分×2 | 10s |
| 诅咒增幅 | 💀 | 得分×2.5，但饱食加速下降 | 12s |
| 完美早餐 | 👑 | 食物密度2倍 + 所有得分2倍 | 15s |

- 左侧 buff 栏 UI：显示激活 buff 图标/名称/进度条/剩余时间
- 即将过期时闪烁警告，过期时淡灰色结束提示
- 合成成功时光环扩散 + buff 名称浮动 + 粒子散射特效
- 厌恶食物被 buff 抵消时显示特殊表情 + "厌恶被抵消!" 提示

### 弹窗面板（HTML实现）

**食物图鉴**
- HTML弹窗实现，完美适配各种屏幕
- 分类筛选（全部/自然/液体/奇怪/美味/抽象）
- 滚动浏览所有食材
- 显示食材名称、分数、类别
- 点击遮罩或关闭按钮关闭

**配方面板**
- HTML弹窗实现
- 显示解锁进度
- 已解锁料理：显示名称、分数、优先级、条件、描述
- 未解锁料理：显示基础提示信息
- 滚动浏览所有料理

### 存档系统

- 自动保存最高分
- 保存总投喂次数
- localStorage持久化存储

### 鼠标能量系统

**核心机制**
- 光环替代传统鼠标光标，跟随鼠标移动
- 多层光环视觉效果：外发光层、主光环、内环、核心光点、脉冲效果层
- 鼠标能量系统：
  - **空闲时**快速恢复能量（2/秒）
  - **拖拽食物时**按拖拽距离消耗能量（每像素0.03，拖满屏约消耗36）
  - **能量低于30%**：进入"粘滞区"，拖拽增量被阻尼衰减，产生鼠标DPI降低的沉重感
  - **能量耗尽**：无法拖拽食物，进入"虚弱状态"（持续8秒，恢复后获得30能量）
  - 全过程有明确视觉反馈：光环闪红→阻尼提示文字跟随→"拖不动啦~"弹窗

### 随机事件系统

- 每隔 8-15 秒随机触发特殊事件（10种，含正面和负面）
- 事件效果强于常规 buff：得分×3、食材风暴、能量泄漏、暗影笼罩等
- 触发时屏幕中央大字通知（图标+名称+描述），带闪光特效
- 事件与 buff 系统叠加，增加游戏不可预测性

### 成就系统

- **11个成就**：从"初次合成"到"美食收藏家"
- 成就完成自动解锁对应的配方
- 成就面板（右上角🏆按钮）显示进度条和奖励预览
- 持久化记录（localStorage）

### 配方系统

- **22个配方**，3种稀有度（普通/稀有/传说）
- **条件冲突已修复**：每个配方的维度条件互不覆盖，不存在"永远无法合成"的配方
- **惩罚配方**（3个）：错误组合产生负面效果（扣分、debuff）
- **有舍有得配方**（4个）：高风险高回报或低分换强buff的战术选择
- 配方按稀有度分组展示，条件用直观的emoji+维度统计显示
- 每种配方有专属合成特效：成功(彩色光)、惩罚(绿色毒雾)、取舍(暗金光芒)

**情绪联动**
- 光环颜色随怪兽情绪变化：
  - 开心（饱食度>70）：金色/珊瑚橙
  - 正常（饱食度20-70）：薄荷绿/天蓝
  - 伤心（饱食度<20）：薰衣草灰/冰蓝
- 开心时光环更明亮、拖尾更长
- 伤心时光环更黯淡、效果减弱

**视觉效果**
- 呼吸动画（光环大小随时间脉动）
- 拖尾粒子（移动时产生渐变消失的粒子）
- 闪烁粒子（开心状态时随机出现）
- 喂食反馈（喜爱食物触发爱心粒子，厌恶食物触发震荡效果）

**UI显示**
- 右下角能量条显示当前血量
- 状态指示：虚弱/能量不足/能量充沛

### 怪物互动 AI（实验性功能）

**行为系统**
- 怪物根据情绪状态主动与鼠标互动
- 开心状态（饱食度>70）：
  - 追逐鼠标（显示→箭头）
  - 发射治愈爱心恢复鼠标能量
- 伤心状态（饱食度<20）：
  - 躲避鼠标（显示!感叹号）
  - 发射攻击弹幕造成鼠标伤害
- 中等状态（饱食度20-70）：
  - 随机追逐或躲避

**攻击系统**
- 弹幕攻击：发射红色圆球造成伤害
- 治愈爱心：发射粉色爱心恢复能量
- 命中特效：粒子爆发 + 闪光效果

## 问题定位指南

### 按钮点击无响应

1. 检查 Canvas 按钮是否被遮挡：
```js
// 获取按钮对象，检查 z 值
GameDebug.help()
```

2. 检查弹窗 DOM 是否存在：
```js
document.getElementById('encyclopedia-modal')  // 应返回 DOM 元素
document.getElementById('recipe-modal')        // 应返回 DOM 元素
```

3. 检查弹窗是否正确显示：
```js
document.querySelector('#encyclopedia-modal.active')  // 打开时应返回元素
```

### 食物不生成

1. 检查活跃食物数量：
```js
GameDebug.getActiveFoods().length  // 应该 >= 0
```

2. 手动生成测试：
```js
GameDebug.spawnRandomFood()  // 应该生成一个食物
```

3. 清除后重新生成：
```js
GameDebug.clearAllFoods()
GameDebug.spawnMultipleFoods(5)
```

### 合成不工作

1. 检查合成炉状态：
```js
GameDebug.getForgeFoods()    // 查看炉中食材
GameDebug.canCraft()         // 检查是否可合成
```

2. 强制合成：
```js
GameDebug.craft()
```

3. 解锁配方测试：
```js
GameDebug.unlockAllRecipes()
GameDebug.openRecipePanel()  // 查看效果
```

## 核心定位：怪诞养成游戏

与市面上温馨可爱的养成游戏（如《我的汤姆猫》）形成差异化，我们主打**猎奇、异质、不安但迷人**的怪诞风格。

---

## 规划方向

> **注**: Buff 系统已于 2026-04-24 实现——合成料理产物具有即时临时效果，回到主循环影响游戏体验。合成系统与主循环割裂的问题已解决。

### 方向二：进化/变异树系统【既定目标】

**核心概念**：喂什么，长成什么样——进化是"异化"，不是成长

#### 进化路径设计

| 进化方向 | 触发食材 | 外观变化 | 特性 |
|---------|---------|---------|------|
| **血肉化** | 血肉/内脏类 | 身体软化、长出触手、脉动效果 | 高饱食度上限 |
| **骨骼化** | 骨头/化石类 | 骨刺外露、关节异响、身体硬化 | 高防御力 |
| **腐蚀化** | 毒液/脏水类 | 荧光绿、滴落腐蚀液、部分透明 | 毒属性攻击 |
| **燃烧化** | 岩浆/火药类 | 岩浆纹理、身体冒烟、局部着火 | 火属性强化 |
| **多眼化** | 眼球类 | 身体各处冒出眼球、注视玩家 | 隐藏食材可见 |
| **虚空化** | 抽象类（星星/代码） | 身体半透明、宇宙纹理 | 吞噬能力 |

#### 进化动画（视觉冲击力）

- 身体**裂开**，新肢体钻出
- 皮肤**熔化**，露出底层组织
- 眼球从皮下**涌出**
- 触手从身体**刺出**
- 进化时屏幕**抖动** + 怪物**嘶吼**

#### 进化树可视化

```
                    ┌─ 多眼化 Lv3 ── 全视者
                    │
        ┌─ 多眼化 ──┤
        │           └─ 多眼化 Lv2
        │
初始 ───┼─ 血肉化 ─── 血肉化 Lv2 ─── 肉山
        │
        ├─ 腐蚀化 ─── 腐蚀化 Lv2 ─── 毒雾
        │
        └─ 虚空化 ─── 虚空化 Lv2 ─── 深渊
```

### 方向五：怪物能力解锁系统【既定目标】

**核心概念**：能力不是"技能"，是"异能/诅咒"

#### 能力设计

| 能力名 | 效果描述 | 解锁条件 |
|-------|---------|---------|
| **分裂** | 身体分裂成多个小怪，分头吞噬食材 | 血肉化达到 Lv2 |
| **寄生** | 食材不消失，而是"长"在怪物身上，获得其特性 | 多眼化达到 Lv2 |
| **吞噬** | 核心器官张开，直接吸入周围所有食材 | 虚空化达到 Lv2 |
| **诅咒** | 发出尖啸，屏幕抖动，稀有食材出现概率提升 | 腐蚀化达到 Lv2 |
| **暴食** | 饱食度上限突破，身体无限膨胀 | 燃烧化 + 血肉化双修 |
| **硬化** | 受到负面效果减半，身体发出金属光泽 | 骨骼化达到 Lv3 |

#### 能力触发动画

- **分裂**：身体撕裂，小怪钻出，各自独立行动
- **寄生**：食材刺入身体，蠕动融入，获得食材特性
- **吞噬**：核心器官张开黑洞般的大嘴，吸入周围
- **诅咒**：所有眼球同时转向屏幕外，发出尖啸

---

### 方向六：怪物分裂繁殖系统【既定目标】

**核心概念**：怪物不是孤独的个体，而是一个"族群"

#### 分裂机制

```
进化到一定阶段 → 身体分裂 → 诞生新怪物（继承部分特性）
                                    ↓
                            每只怪物有独特进化路线
                                    ↓
                            建立"怪物家族谱系"
```

#### 繁殖系统

| 行为 | 条件 | 结果 |
|-----|------|------|
| **自我分裂** | 进化达到阈值 | 身体撕裂，生成继承特性的小怪 |
| **杂交繁殖** | 两只怪物"接触" | 产生混合特性的后代 |
| **变异繁殖** | 特殊料理触发 | 产生稀有变异个体 |

#### 家族谱系

- 记录每只怪物的"血统"
- 显示遗传特征传递
- 追溯祖先/后代关系

#### 持续动力

- 培育不同进化分支的怪物
- 尝试各种杂交组合
- 收集不同品种的怪物
- 追求稀有变异个体

#### 怪诞点

- 分裂动画要诡异——身体撕裂、从内部钻出、自我复制
- 后代可能继承"缺陷"特性
- 某些组合产生不可名状的怪物

---

### 方向八：随机遭遇事件系统【未来可选】

**核心概念**：养成过程有意外，不是单纯点点点

#### 事件示例

| 事件 | 描述 | 玩家选择 |
|-----|------|---------|
| **流浪怪物来访** | 奇怪怪物出现在屏幕边缘 | 驱赶 / 喂食 / 收留 |
| **怪物噩梦** | 怪物醒来后身体发生变化 | 观察 / 安抚 |
| **食材变异** | 食材突然变成活体 | 杀掉喂食 / 放走 / 观察 |
| **怪物蛋** | 怪物产下一颗蛋 | 孵化（取决于最近喂的食物）|
| **诅咒降临** | 屏幕变暗，怪物被标记 | 用特定料理解除 |

#### 设计要点

- 事件要有不安感和好奇心
- 每次游戏体验不同
- 玩家期待下一个事件

---

### 方向九：怪物梦境世界【未来可选】

**核心概念**：怪物睡觉时进入另一个维度

#### 梦境机制

```
怪物入睡 → 点击进入梦境 → 迷你游戏/探索
                              ↓
                     梦境中获得：
                     - 稀有食材
                     - 进化线索
                     - 怪物记忆碎片
                     - 神秘符文
```

#### 梦境特点

- 画风更加扭曲、抽象
- 有小游戏：追逐、躲避、收集
- 梦境反映怪物的心理状态
- 深层梦境有更稀有奖励

#### 持续动力

- 探索梦境深度
- 收集梦境图鉴
- 解锁怪物潜意识

---

## 怪物基础设计

每只怪物有一个**核心异质器官**，是它的灵魂所在：

| 怪物 | 核心器官 | 特色 | 初始能力 |
|-----|---------|-----|---------|
| **眼魔** | 巨大的中央眼球 | 全身布满眼睛，注视玩家 | 可见隐藏食材 |
| **触手怪** | 蠕动的触手团 | 触手主动抓取食物 | 抓取范围+20% |
| **血肉块** | 裸露的心脏 | 剧烈脉动，血肉感强 | 饱食度上限+10 |
| **骨拼体** | 骷髅头 | 发出咔咔响声 | 负面效果减半 |

### 进食动画差异化

食物不是"消失"，而是：
- 被**吸入**核心器官
- 在怪物体内**蠕动移动**
- 被怪物**包裹消化**

背景：深紫 #1a0a1a、暗红 #2a1010、腐绿 #0a1a0a
怪物：血红 #aa2020、荧光绿 #00ff44、骨白 #e8e8d8

- 背景加**噪点**、**脉动**效果
